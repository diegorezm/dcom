# dcom

Um app para conversar em comunidade, com a simplicidade do Discord, mas leve: abre rápido e gasta pouca memória.

> **Status:** o projeto está no começo. Já dá para ver a cara do app com conversas de exemplo, mas ainda não dá para conversar de verdade. Os passos abaixo mostram como vai funcionar na primeira versão.

## Para quem é

Grupos de amigos, grupos de estudo, times pequenos e comunidades de até algumas centenas de pessoas.

## O que você vai poder fazer

- Criar servidores e canais de texto
- Chamar pessoas com um convite
- Trocar mensagens privadas
- Mencionar pessoas e receber notificações

Chamadas de voz virão depois da primeira versão.

## Como usar

1. Baixe e abra o dcom.
2. Fique com o servidor oficial ou cole o endereço de outro.
3. Entre na sua conta pelo navegador.
4. Crie um servidor ou entre em um com um convite.

## Como rodar o seu próprio dcom

Você pode hospedar tudo por conta própria:

1. Instale o Docker.
2. Baixe este projeto e preencha as configurações.
3. Rode `docker compose up`.
4. No app, cole o endereço da sua instância.

Quando essa parte estiver pronta, um guia vai explicar cada configuração.
